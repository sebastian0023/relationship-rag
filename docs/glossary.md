# Domain glossary

| Term            | Meaning                                                                              |
| --------------- | ------------------------------------------------------------------------------------ |
| Couple          | The sole tenancy boundary containing exactly two invited members.                    |
| Owner           | The member who administers the private couple space and invitations.                 |
| Partner         | The second invited member with access to the shared experience.                      |
| Memory          | A dated relationship event with text, tags, location, and optional private media.    |
| Timeline        | Memories ordered chronologically for the authenticated couple.                       |
| Source document | A normalized, non-public representation of a memory used for RAG ingestion.          |
| Citation        | A memory identifier supporting a generated answer or card draft.                     |
| Grounded answer | A response whose relationship claims are supported by retrieved memories.            |
| Abstention      | A safe response stating that the requested information has not been provided.        |
| Card draft      | Editable generated content that cannot be delivered until explicitly saved and sent. |
| Inbox item      | A card delivery visible only to its intended recipient.                              |
| Delivery        | An idempotent transition that places a card in the recipient's inbox.                |
